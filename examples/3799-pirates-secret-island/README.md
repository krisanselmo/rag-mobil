# Example: "Pepper and the Pirate's Hat" (set 3799)

A story generated by `rag-mobil` for [3799 "Pirates Secret Island"](https://playmodb.org/cgi-bin/showinv.pl?setnum=3799)
(1991), with the default options (English, 7-year-old reader, about 600 words, `planned`
method), `--scene-setup` and `--illustrate`.

- [`story.md`](story.md): the story, with "Set the scene" before each part and "In your box" at the end
- [`booklet.pdf`](booklet.pdf) / [`booklet.html`](booklet.html): the illustrated booklet
- [`session/illustration.svg`](session/illustration.svg): the cover picture, from [`session/illustration.prompt.txt`](session/illustration.prompt.txt)
- [`inventory.json`](inventory.json): the inventory fetched from PlaymoDB (`--inventory-json`)
- [`session/`](session/): the 7 prompts sent to the model and its answers

The model is Claude, through [`--replay`](../../README.md#bypassing-the-llm-end-to-end-tests):
Claude wrote each answer in `session/`, and the rest of the pipeline ran for real (plan
validation, drafting part by part, review, revision). The review caught a note in a bottle
that is not in the box, and the revision has Barnaby tell his secret instead.

The cover picture was drawn by Claude too, as an SVG answering the illustration prompt, not by
an image model: with `--illustrate --image-model gpt-image-1` (or `gemini-2.5-flash-image`)
and an API key, the same prompt gives a toy-photography picture instead.

Reproduce it without network access or API key:

```bash
rag-mobil 3799 --inventory-file examples/3799-pirates-secret-island/inventory.json \
  --scene-setup --illustrate --replay examples/3799-pirates-secret-island/session \
  --booklet booklet.pdf > story.md
```
